## 中文显示层(2026-09-10,响应"显示需要中文,识别是乌克兰语")

- **原则**:识别与入库保持乌克兰语原文(证据、待处理、合并逻辑不变);只有**显示**本地化为中文。
- **三层中文名**:
  1. 人工精选 170 条(`data/place_names_zh.json`,覆盖主要城市/基辅各区与社区/州/高频地名);
  2. Wikidata 标签 3,954 条(`scripts/fetch_zh_names.py` 按 GeoNames ID 抓取,OpenCC 转简体,可重复更新);
  3. 同名+同州继承(无 GeoNames ID 的 KATOTTH 补充条目)。
- **目录治理**:过滤自然/纪念物名(如 "Два вікові дуби")、描述性短语(如 "... пункт пропуску ...")、通用词/国名变体(Нова/Ukrayina 等);运行时重复条目按既有目录去重。
- **地图标签**:改用 DOM 标记(栅格样式无中文字形,符号层渲染不出中文);州/区/城市/镇始终标注,村镇仅在新鲜时标注,总量上限 60 防拥挤。
- **实测**:事件地名中文覆盖 **90%**(1198/1331);DOM 验证地图标签与事件流均为中文(敖德萨/库皮扬斯克/基辅/哈尔科夫/第聂伯罗/利沃夫…);发布图中文字像素占比 0.00%→0.29%(标签可见)。测试 82/82。
- 残量约 10% 为无标准中文译名的小村庄(显示乌克兰语原名,属正常)。

## 评审结论:通过,可以开工

交接文档五件套齐全,数据语义 12 条不变量、分步验收标准、明确的不做清单,与我们此前"奥卡姆 + 第一性原理"的方向一致且更严格。hifi 原型的色值已用脚本核验与 §4 规范一致,7 项回归测试记录诚实(明确区分"主代理检查"与"独立审阅")。n8n 导出分析到位(processed 布尔、无租约、占位 PATCH),结论"只作外围自动化、不作核心事实库"正确。

## 接受的修正(以 HANDOFF 为准,不再改回)

1. v1 暂不引入 Redis、专用快照表、PostGIS 专属功能——带索引查询先测量再升级(4–10 群规模足够)。
2. 无可靠坐标的地点**不上图**,进入"待定位"队列(取消原"灰点即时发布"方案)。
3. `report_count` ≠ 独立证实数;报告数、频道数、来源独立性分开记录。
4. 相对时间锚定**来源消息发布时间**,不锚定处理时刻;保留时间依据字段。
5. 同城同类短时间窗内是**保守候选合并**,保留证据与拆分能力,不宣称同一事件。
6. 历史默认返回"最新修正后的过去事件";"当时认知重建"是另一功能,首版不做。
7. 采集连接与账号/session、来源订阅分开建模;Bot API 与 Telethon 的取舍在接入真实来源时按实际授权条件复核(不继承绝对结论)。
8. 安全:运营接口服务端鉴权,共享页做原文/来源信息授权投影;裸链接不等于访问控制。

## 本轮修复的缺陷(均有回归测试或实测证据)

1. **MapView 竞态**:事件 fetch 可能早于 MapLibre style load 到达,此时 events source 尚未创建,setData 被跳过且不再补画 → 地图标记随机丢失。修复:数据经 ref 保持,load 时刻立即补一次 setData。
2. **词对模糊匹配过宽**:`fuzz.token_set_ratio` 对"包含地名词的短语"恒为 100,导致 "Обстріл Херсона" 与 "Херсона хвилин" 都被匹配成 Херсон,产生重复候选/重复证据(UNIQUE 冲突)。修复:改用 `fuzz.ratio`;多词短语仅允许精确别名(回归测试 test_multiword_phrase_no_fuzzy)。
3. **歧义消解空串恒真**:admin2 为空时 `"" in ctx` 恒 True,同名地点上下文消歧失效。修复:仅非空 admin 字段参与匹配。
4. **Chrome `--timeout` 截图模式不可靠**:该模式在此 Chrome 版本下会中止页面 fetch,截图中事件标记随机缺失(耗时调查确认:页面状态本身正常,CDP 实测 title/事件数均正确)。修复:发布器改用 CDP 等待 `export-tag` 出现非零事件数后 `Page.captureScreenshot`。
5. **候选 ID 未 flush**:ingest 响应里 candidates 为 null;已在返回前 flush(测试断言 ID 为整数)。
6. **Telethon 维护状态复核**(2026-09-07 GitHub API):archived=true、最后推送 2026-02-21(与调研结论一致);tdl archived=false、2026-08-31 活跃。锁依赖时按"锁定版本 + 独立容器"策略执行。
